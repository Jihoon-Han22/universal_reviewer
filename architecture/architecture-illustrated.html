전체
기술 세부와 설계 근거
  • 현재 동작(CURRENT_REPRODUCTION) 기준. 숫자는 설명용 예시입니다. 모든 요청과 결과는 서버가 중계합니다.
  • 진행 순서: 사람의 명시적 승인 뒤에만 대상 분석을 시작합니다. 승인본은 고정합니다.
  • 일반 문서 읽기: 원본을 먼저 읽고 LLM 해석을 서버·별도 LLM으로 검증합니다. 문제 위치를 검증한 뒤 같은 E2B의 고정 reader로 재조회합니다. 검증 최초 포함 최대 3라운드, 재조회 최대 2회. 모델 생성 코드를 실행하지 않습니다.
  • Excel 기준 탐색: 문서 이해 세션을 닫고 별도 E2B를 열어 실제 범위를 최대 2회 읽습니다.
  • PDF·사진: E2B 첫 읽기·종료 뒤 시각 전사와 독립 원본 대조를 최대 3라운드 수행합니다. 시각 대상 문서의 별도 사실 추출에는 승인 기준을 주지 않습니다.
  • 판정: LLM 제안 뒤 서버가 근거·수치·조건·적용성을 검사합니다. 예시의 20 이상/18은 같은 단위·조건으로 가정합니다. 품질 문제는 미해결·부분 처리·확인 필요로 보존합니다.
  • 맞춤 화면: 디자인 JSON → 서버 고정 HTML → E2B 구조·데이터 검사 → 실패 진단으로 수리. 모델 호출 합계 최대 3회(최초 포함). 실패하면 기본 화면, 취소면 중단. 판정값은 바꾸지 않습니다.
  • 문서 이해·Excel 기준 탐색·대시보드는 서로 다른 샌드박스 세션입니다. 결과표와 대장 사본 출력 자체에는 별도의 LLM 반복이 없습니다.

## 주요 차이

한 파일에서 원래 PDF의 텍스트 페이지와 이미지 페이지, 양호한 사본과 저품질 사본, 세로·가로·거꾸로 된 페이지가 섞입니다. 2-up 13쪽과 끼워 넣은 메모 9쪽이 있습니다. 일부 구간의 순서를 바꾸고 비대상 첨부 페이지를 중복 삽입했습니다. 어떤 페이지에 문제가 생겼는지는 모델 입력에 별도로 알려주지 않습니다.

문서가 원래 가진 페이지 회전은 유지했고, 추가 변형 회전은 페이지 이미지에 적용했습니다. 따라서 PDF `/Rotate`만 확인해도 모두 해결되는 문제가 아닙니다. 휴대폰 촬영은 원근 투영·명암·탁자색 배경을 합성한 것으로 실제 촬영 사진이 아닙니다. 필기는 필기체 폰트와 흔들린 획으로 합성했으며 실제 사람의 필적·서명이 아닙니다.

## GT와 평가

모델에는 `inputs/`만 전달합니다. `golden/`, `preview/`, `evaluation/`, 비교집 및 갤러리는 개발자용입니다. 같은 v2 문서에서 파생한 v3 사본을 별도 독립 테스트셋으로 취급하지 마세요. 원본 가족을 같은 split에 묶어야 합니다.

`golden/page_map.json`은 v3 물리 쪽 → v2 원본 쪽의 연결, 적용 효과 순서와 매개변수, 페이지 난수 시드, 3×3 좌표 변환을 기록합니다. 근거 좌표는 화면에 보이는 PDF 기준 왼쪽 위 원점의 point입니다. 한 장에 두 페이지가 있으면 각 구성요소의 좌표 변환을 따로 제공합니다. 절반 회전 효과는 점수 대상이 아닌 부속 페이지 및 비교집에만 적용했으며, 그 효과의 임의 위치에는 단일 행렬을 쓰지 마세요.

비교집은 효과 선택·육안 비교용으로 채점하지 않습니다. 실제 회귀 평가는 8개 혼합 보고서와 `canonical_answer.json`을 사용합니다. GT의 라벨 변경은 합성 작성 정책이며 독립 전문가 교차 검토나 실제 OCR 성능 측정을 뜻하지 않습니다.

```
python evaluation/evaluate.py golden/canonical_answer.json
python evaluation/evaluate.py failed_predictions/F02_guess_hidden_thermal.json
```

첫 명령은 성공, 두 번째는 실패(exit 1)가 정상입니다. 평가기는 값·기준·판정·페이지 검색·출력셀을 검사하며 bbox IoU나 OCR 자체를 실행하지 않습니다.

로컬 생성 코드는 작업공간 `tmp/ralph_v3/build.py`에 있습니다. 페이지 시드는 UTF-8 `case_id:원본쪽:mixed` 문자열의 unsigned CRC32이며, 효과 순서와 원본 PDF SHA-256은 `generation_recipe.json`에 기록했습니다. 비교집은 마지막 seed 토큰으로 효과 key를 사용합니다. 동일 라이브러리 버전과 원본으로 효과를 재현할 수 있으며 PDF 메타데이터까지 바이트 동일함을 보장하지는 않습니다.
